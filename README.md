# 🏥 AxonCare Insights — Healthcare Data Analytics

### Healthcare Data Analysis & Dashboard Reporting | Excel · Power Query · SQL · Power BI · Tableau

## 📌 Project Overview

**AxonCare Insights** is a healthcare data analytics capstone project focused on organizing healthcare data and presenting meaningful information through data analysis, SQL queries, and interactive dashboards.

The project works with healthcare datasets covering patient demographics, doctors, hospital visits, treatments, laboratory tests, billing, and insurance claims. It demonstrates the application of data preparation, database querying, and business intelligence tools to make healthcare information easier to understand.

Using **Microsoft Excel, Power Query, MySQL, Power BI, and Tableau**, this project brings together data preparation and dashboard reporting in a healthcare analytics context.

## 🎯 Project Objectives

- Organize and prepare healthcare data for analysis.
- Work with patient, doctor, and hospital visit records.
- Examine laboratory test status information.
- Work with billing and insurance claim datasets.
- Use SQL to query and retrieve healthcare information.
- Create visual reports and dashboards using Power BI and Tableau.
- Present healthcare information in a structured and understandable format.

## 🗂️ Dataset Overview

The project includes eight healthcare data categories:

1. **Patient** — Patient records and demographic details.
2. **Doctor** — Doctor information and active status.
3. **Visit** — Healthcare visit records and department information.
4. **Treatment** — Treatment-related records.
5. **Lab Test** — Laboratory test records and status categories.
6. **Billing** — Billing and payment-related information.
7. **Insurance Claims** — Insurance claim records.
8. **Insurance Provider** — Insurance provider information.

These datasets represent different aspects of healthcare operations and provide the foundation for the project's data preparation, SQL work, and visual reporting.
